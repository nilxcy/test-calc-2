# Desk Tape Calculator

A desk-style calculator with operator precedence, a live result preview and a paper tape that keeps past totals.

## Structure

```
desk-tape-calculator/
├── index.html      # markup
├── css/style.css   # styles, light and dark themes
└── js/app.js       # calculator logic, tape, keyboard support
```

## Run

Open `index.html` in a browser. No build step or server needed.

## Keyboard

`0–9`, `+ - * /`, `.`, `%`, `Enter` (=), `Backspace`, `Esc` (clear).
